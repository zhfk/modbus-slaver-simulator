## 测试阈值与范围

混合负载默认 1004 点位（1000 个信号加 4 个温控点）、4 个客户端，每客户端目标 10Hz，策略周期 0.1 秒，两个历史点位每秒采样。实时订阅 50 点位、每秒请求完整快照，每 30 秒重连、暂停／恢复策略，每 120 秒停止／启动设备并重连协议客户端。阈值为 RSS ≤256MiB、暖机后增长 ≤32MiB、P99 ≤250ms、事件循环延迟 ≤200ms、队列 ≤10000 条／16MiB、总文件占用 ≤1536MiB、暖机后采样平均 CPU ≤单核 80%；线程、句柄和任务数增长也设有限额。资源、请求数、源代码指纹保存在报告中；P95／P99 为最多最近 10000 个请求循环样本，写入客户端的循环包含读、写、回读三次操作。

磁盘余量不足通过受控健康指标注入验证，数据库只读使用实际 SQLite `query_only` 注入；快照和备份写入错误使用受控 I/O 异常注入。这些检查不能冒充目标 Windows 文件系统的实际写满、断电或防火墙验收。Windows Server 2022 原生包检查已完成；目标用户 Windows 桌面、服务账户和实际跨机器网络检查仍未执行。

这些阈值是本次选定负载的发布门槛，不是对所有机器和 10000 点位上限的性能保证。平台、Python 版本与实际负载写入报告；未测量的硬件和网络路径保持未验收状态。
